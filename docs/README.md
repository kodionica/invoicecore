# InvoiceCore dokumentacija

Ovaj folder je referenca zasnovana na kodu, migracijama, rutama i testovima. Dokumenti razlikuju implementirano stanje, poznata ograničenja i otvorena poslovna pitanja.

## Indeks

- arhitektura.md — stack, DDEV i struktura
- autentifikacija-i-tenant.md — Sanctum, aktivna firma i izolacija
- kompanije-klijenti-podesavanja.md — firme, banke, timezone i settings
- fakture.md — fakture, iznosi, statusi, plaćanje i numeracija
- kpo.md — KPO generisanje, regeneracija, soft-delete i PDF
- dokumenti-i-pdf.md — invoice/KPO PDF, verzije, retention i e-mail
- frontend.md — React tokovi i AppContext
- local-backup.md — host backup/restore
- testiranje-i-razvoj.md — DDEV komande i bezbedne provere
- otvorena-pitanja.md — računovodstvene odluke i ograničenja
- plan-razvoja.md — ažurirani prioriteti

Kada se promene ruta, model, migracija, API ugovor, poslovno pravilo ili korisnički tok, ažurirati odgovarajući dokument. Ne unositi tajne ili lokalne apsolutne putanje.
